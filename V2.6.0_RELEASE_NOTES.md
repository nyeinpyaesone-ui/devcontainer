## ⚡ Performance Profiler

### Overview
A comprehensive performance analysis tool that examines your devcontainer configuration and provides actionable insights to optimize build time, image size, and resource usage.

### Core Features

#### 1. Performance Scoring
- **Overall Score (0-100)** - Comprehensive performance rating
- **Letter Grade (A-F)** - Quick visual assessment
- **Circular Progress Indicator** - Visual representation of score
- **Color-Coded Grades** - Green (A) to Red (F) for quick identification

#### 2. Metrics Estimation
- **Build Time** - Estimated time to build the devcontainer (seconds)
- **Image Size** - Estimated Docker image size (MB)
- **Memory Usage** - Estimated runtime memory consumption (MB)

#### 3. Issue Detection (10+ Checks)
Automatically identifies performance issues across multiple categories:

**Toolchains**
- Multiple toolchains enabled
- Heavy toolchains (Java, .NET, Python)
- Estimated impact and savings

**Features**
- Docker-in-Docker overhead
- Feature-specific performance costs

**Tools**
- All tool groups enabled
- Unnecessary tool installation

**Network**
- Many ports exposed
- Attack surface analysis

**Extensions**
- Too many VS Code extensions
- Startup time impact

**Optimization**
- Named volume not enabled
- Git optimizations incomplete
- Clone strategy analysis

**Base Image**
- Ubuntu vs Alpine/Debian comparison
- Size optimization opportunities

#### 4. Issue Details
Each issue includes:
- **Severity Level** - Critical, High, Medium, Low
- **Category** - Toolchains, Features, Tools, Network, Extensions, Optimization, Base Image
- **Title** - Clear issue description
- **Description** - Detailed explanation
- **Impact** - Quantified performance impact
- **Recommendation** - Specific action to take
- **Estimated Savings** - Quantified improvement (time/size)

#### 5. Severity-Based Scoring
Issues are weighted by severity:
- **Critical** - -20 points
- **High** - -15 points
- **Medium** - -8 points
- **Low** - -3 points

**Optimization Bonuses:**
- Named volume enabled: +10 points
- Git optimizations (4+): +5 points
- Shallow clone: +5 points

### User Interface

## 🔧 Technical Implementation

### Performance Profiler Engine (`src/lib/performance-profiler.ts`)

**Core Function: `profilePerformance(config)`**

**Analysis Categories:**
1. **Toolchain Analysis**
   - Count enabled toolchains
   - Identify heavy toolchains (Java, .NET, Python)
   - Calculate build time and size impact

2. **Feature Analysis**
   - Check Docker-in-Docker overhead
   - Calculate feature-specific costs

3. **Tool Group Analysis**
   - Check if all groups enabled
   - Identify unnecessary tools

4. **Port Analysis**
   - Count exposed ports
   - Assess attack surface

5. **Extension Analysis**
   - Count VS Code extensions
   - Estimate startup impact

6. **Optimization Analysis**
   - Named volume status
   - Git optimization count
   - Clone strategy analysis

7. **Base Image Analysis**
   - Compare Ubuntu vs alternatives
   - Size optimization opportunities

**Scoring Algorithm:**
```typescript
score = 100
  - (critical_count * 20)
  - (high_count * 15)
  - (medium_count * 8)
  - (low_count * 3)
  + optimization_bonuses
```

**Metrics Calculation:**
- **Build Time**: Base (30s) + features (15s each) + toolchains (45s each) + tools (8s each) + ports (2s each)
- **Image Size**: Base (150MB) + features (80MB each) + toolchains (250MB each) + tools (50MB each) + extensions (5MB each)
- **Memory Usage**: Base (512MB) + features (128MB each) + toolchains (256MB each) + ports (64MB each)

### Developer Guide

**Performance Profiler API:**
```typescript
import { profilePerformance } from "./lib/performance-profiler";

const profile = profilePerformance(config);

// Access metrics
console.log(profile.score);        // 0-100
console.log(profile.grade);        // "A" - "F"
console.log(profile.buildTime);    // seconds
console.log(profile.imageSize);    // MB
console.log(profile.memoryUsage);  // MB

// Access issues
profile.issues.forEach(issue => {
  console.log(issue.severity);     // "critical" | "high" | "medium" | "low"
  console.log(issue.category);     // "Toolchains" | "Features" | etc.
  console.log(issue.title);        // Issue title
  console.log(issue.impact);       // Impact description
  console.log(issue.recommendation); // Action to take
  console.log(issue.estimatedSavings); // Quantified savings
});
```

**Scoring Algorithm:**
- Base score: 100
- Deductions based on issue severity
- Bonuses for optimizations
- Clamped to 0-100 range

**Metrics Calculation:**
- Build time: Sum of component build times
- Image size: Sum of component sizes
- Memory usage: Sum of component memory requirements
