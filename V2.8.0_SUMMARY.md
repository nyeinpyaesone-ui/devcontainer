## 🚀 Quick Start

### Try Version Control

1. **Open Version Control**
   - Click the git icon (🔀) in the header
   - Modal opens with four tabs

2. **Create a Branch**
   - Switch to Branches tab
   - Enter branch name (e.g., "feature/new-config")
   - Click "Create"
   - Switch to new branch

3. **Make Changes**
   - Configure your devcontainer
   - Make configuration changes

4. **Commit Changes**
   - Enter author name
   - Enter commit message
   - Click "Commit"
   - View in Commits tab

5. **Tag Versions**
   - Switch to Versions tab
   - Enter tag name (e.g., "v1.0-stable")
   - Click "Tag"
   - View tagged versions

6. **Add Remote**
   - Switch to Remotes tab
   - Enter remote name (e.g., "origin")
   - Enter remote URL
   - Click "Add Remote"
   - Push/pull as needed
