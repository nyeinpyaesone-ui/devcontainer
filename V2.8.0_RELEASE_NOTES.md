# GHCR Devcontainer Forge v2.8.0 Release Notes

## 🔀 Version Control & Git Integration

**Release Date:** 2026-01-XX  
**Build Status:** ✅ Passing (4.13s, 87 modules)

### Overview

v2.8.0 introduces comprehensive **Version Control & Git Integration** capabilities, enabling professional git workflow management with branch control, commit history, and remote repository synchronization.

---

### 🎯 New Features

#### 1. Git Integration Engine (`src/lib/git-integration.ts`)
- **Branch Management**: Create, switch, delete, and merge branches
- **Commit Tracking**: Full commit history with author attribution
- **Remote Repository Support**: Add, remove, push, and pull from remotes
- **Version Management**: Tag versions and checkout historical configurations
- **Status Tracking**: Monitor modified, staged, and untracked files
- **Persistent Storage**: All git data saved to localStorage
- **Event-Driven Architecture**: Real-time updates via subscriber pattern

#### 2. Version Control Panel (`src/components/VersionControlPanel.tsx`)
- **Branch Management Tab**:
  - Create new branches from current branch
  - Switch between branches
  - Delete non-main branches
  - View branch statistics (ahead/behind counts)
  - Visual indicators for current branch

- **Commits Tab**:
  - View complete commit history
  - See commit messages, authors, and timestamps
  - Display commit hashes and branch information
  - Revert commits with one click
  - Relative time formatting

- **Versions Tab**:
  - View all configuration versions
  - Tag versions with custom labels
  - Checkout historical configurations
  - See version metadata (commit hash, branch, author)
  - Visual tag indicators

- **Remotes Tab**:
  - Add remote repositories (origin, upstream, fork)
  - View remote URLs and types
  - Push changes to remotes
  - Pull changes from remotes
  - Remove remote connections

#### 3. Git Workflow Features

**Branch Operations:**
- Create branches with custom names
- Switch between branches seamlessly
- Delete branches (protected main branch)
- Track ahead/behind counts
- Visual branch indicators

**Commit Operations:**
- Create commits with messages and author info
- Automatic commit hash generation
- Commit history with full metadata
- Revert commits safely
- Branch-specific commit tracking

**Remote Operations:**
- Add multiple remotes (origin, upstream, fork)
- Push to remote repositories
- Pull from remote repositories
- Remove remote connections
- Remote type classification

**Version Operations:**
- Automatic version creation on commit
- Custom version tagging
- Checkout any historical version
- Version metadata tracking
- Tag management
