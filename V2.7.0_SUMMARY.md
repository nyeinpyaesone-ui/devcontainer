## 🎯 What's New

v2.7.0 introduces **Real-time Collaboration** capabilities, transforming the GHCR Devcontainer Forge from a single-user tool into a team collaboration platform.

### Key Features

#### 1. Collaboration Engine
- **Session Management**: Start, join, and end collaboration sessions
- **User Presence**: Track online/offline status with color-coded indicators
- **Activity Tracking**: Real-time event logging for all changes
- **Conflict Prevention**: Lock/unlock mechanism for editing
- **Comment System**: Team communication within context
- **Persistent Storage**: Session data saved automatically

#### 2. Collaboration Panel
- **Session Controls**: Start/end with user identification
- **Online Users**: See who's active with avatars and status
- **Activity Feed**: Real-time log of all events
- **User Management**: View all collaborators
- **Comments Section**: Team discussion and feedback
- **Lock/Unlock**: Prevent conflicting edits

#### 3. Real-time Features
- **Live Synchronization**: See changes as they happen
- **Presence Indicators**: Know who's online and what they're viewing
- **Activity Tracking**: Automatic logging of all configuration changes
- **User Attribution**: Know who made each change
- **Timestamped History**: Complete audit trail

## 📦 Installation & Usage

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```

### Access Collaboration
1. Open the application
2. Click the collaboration icon (👥) in the header
3. Enter your name and start a session
4. See online users and their activity
5. Make configuration changes (tracked automatically)
6. Add comments for team discussion
7. Lock configuration for review when needed
8. End session when done
